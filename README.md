# Webprogrammierung / Lösung / Bitkits

Dies ist die **Musterlösung** zur Aufgabe „Bitkits" aus der Vorlesung **Webprogrammierung** (Wirtschaftsinformatik, DHBW Karlsruhe), Kategorie *Responsive Webdesign*.

Die Produktseite einer 8-Bit-Sample-Bibliothek wird Mobile-First nachgebaut und für große Bildschirme um ein Dreispalten-Layout erweitert.

Dieses Repository ist Teil der Quellcodes [dhbwka-wwi-webprog-quellcodes](https://github.com/DennisSchulmeister/dhbwka-wwi-webprog-quellcodes) zur Vorlesung Webprogrammierung.
